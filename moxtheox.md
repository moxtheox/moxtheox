# Hi, I'm moxtheox 👋

**Polyglot Engineer focused on Telematics & Fleet Integrations**  
Building lightweight, zero-dependency SDKs and high-concurrency tooling for logistics, IoT, and system runtimes.

---

### 🧠 Engineering Focus

> *"Native primitives over vendor bloat: Zero supply-chain vulnerability, predictable memory, and clean transparency."*

- **Zero-Dependency Architecture:** Standard Web APIs (`fetch`, native headers) over heavy third-party packages.
- **Constant-Memory Streaming:** $O(1)$ heap architectures designed for large-scale symbolic data pipelines.
- **Async Concurrency:** Non-blocking performance using PHP 8.4+ Fibers in synchronous environments.
- **Strict Typing:** Complete interface models for complex domain data (HOS, telemetry, load management).
